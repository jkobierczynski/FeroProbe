# FeroProbe service rules: the probes -sV sends and the rules that read
# the replies.
#
# FeroProbe's own work, written from public protocol specifications and
# from banners that real servers send. nmap's nmap-service-probes is NOT
# used or copied: its licence does not allow redistributing it here. Please
# keep it that way when adding rules.
#
# The format is described in docs/manual.md, "Service rules file". In
# short:
#
#   probe NAME tcp|udp         a probe; its attributes follow, indented:
#     rarity N                 0-9; sent at --version-intensity N or higher
#                              (0: always). Always sent to its own ports.
#     ports LIST               ports the probe is meant for (80,8000-8010)
#     send "TEXT"              bytes to send; \r \n \t \0 \\ \" \xHH work.
#                              Several send lines are joined.
#     pad N                    append N zero bytes to the payload
#     tls                      a TLS handshake instead of a payload
#     listen-ports LIST        (tls only) inside TLS, listen first here
#
#   match SERVICE REGEX        a rule; the first one that matches wins
#   softmatch SERVICE REGEX    names the service only; probing goes on with
#                              the probes that can tell more
#     probe NAME               only for replies to this probe
#     product TEXT             ${1}, ${2}, ... are the regex's groups
#     version TEXT
#     info TEXT                repeatable; joined with "; "
#     host TEXT
#     os TEXT
#     device TEXT
#     cpe TEXT                 repeatable, e.g. cpe:/a:openbsd:openssh:${2}
#
# A REGEX is the rest of the line, run on the raw reply bytes with
# (?s-u): "." matches any byte including newlines, \xNN matches byte NN.
# Use \x20 for a space at either end of a pattern.

feroprobe-service-rules 1
