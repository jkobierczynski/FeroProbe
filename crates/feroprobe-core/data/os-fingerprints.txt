# FeroProbe OS fingerprint database
#
# FeroProbe's own signatures for OS detection (-O). They are written from
# how each TCP/IP stack is documented to behave (kernel sources, vendor
# documentation, RFCs) and from captures of our own machines; nothing here
# comes from nmap's nmap-os-db, whose license does not allow
# redistribution. The format and the tests are described in
# docs/os-fingerprints.md, which also says how to add a signature.
#
# Signatures marked "unverified" have not yet been checked against a
# capture of the real system: send one (feroprobe -O -v prints the
# fingerprint) so they can be confirmed or corrected.
#
# Host firewalls often drop unsolicited ACKs and echo requests, so the
# signatures accept a missing answer to a, c2 and ie.
#
# Block layout:
#   Fingerprint <name>        a signature reported by name
#   Template <name>           only for copying with Like
#   Like <name>               copy an earlier block's tests, class and CPEs
#   Class <vendor>, <family>, <generation>, <device type>
#   CPE <cpe>                 one per line
#   <test> = <alternatives>   alternatives separated by |
#
# Windows are matched with m*N (N times the MSS in the answer, or N times
# the MSS less the 12 bytes of timestamps) and m*max (the largest such
# multiple up to 65535), so one signature fits every link MTU.

# ---------------------------------------------------------------- Linux
#
# Linux writes its SYN-ACK options in a fixed order (MSS, SACK permitted
# with timestamps, window scale) and pads with no-ops where an option is
# left out. It sets DF on SYN-ACKs and resets, and gives them IP ID 0.
# The kernel version shows in the SYN-ACK window: 4 x MSS in 2.6, 10 or
# 20 x MSS in 3.x to 4.18, and the largest multiple of the MSS up to
# 65535 since 4.19 ("tcp: up initial rmem to 128KB and SYN rwin to
# around 64KB"). Timestamps count milliseconds since 4.13; before that
# they followed the kernel's tick rate (100, 250 or 1000 Hz). Recent
# kernels give every connection its own random timestamp offset (ts = R).

Template Linux common
Class Linux, Linux, , general purpose
ttl = 64
s1 = Y
s1.f = SA
s1.o = M,S,T,N,W
s1.df = Y
ws = 2-14
s2 = Y
s2.f = SA
s2.o = M
s3 = Y
s3.o = M,N,N,S
s4 = Y
s4.o = M,N,N,T,N,W
e = Y
e.f = SAE|SA
e.o = M,N,N,S,N,W
a = Y|N
a.f = R
a.w = 0
a.seq = A
a.df = Y
c1 = Y
c1.f = AR
c1.w = 0
c1.ack = S+
c1.df = Y
c2 = Y|N
c2.f = R
c2.w = 0
c2.seq = A
c2.df = Y
ipid = Z
ipid.rst = Z
ie = Y|N

# -------------------------------------------------------------- Windows
#
# Windows writes MSS, then window scale, then SACK permitted, with no-ops
# for alignment, and since Vista leaves TCP timestamps off (it does not
# echo them). Initial TTL 128. IP IDs come from one incrementing counter
# shared by SYN-ACKs and resets; resets to closed ports go without DF.
